# CCTV Control panel

Mode: Operate

Audience: one trusted administrator on phone or desktop. Job: confirm recording health, turn recording on or off, and reach recent clips quickly. Secondary maintenance must remain available without occupying the first view.

## Direction contract

**THESIS:** A precise wall control for the recorder: one state and one switch. Refuse the dashboard wall of cards, gauges, and equal-weight actions.

**OWN-WORLD:** Matte cool-white field, charcoal text, one calm green state color, amber/red only for real warnings. Flat planes, fine rules, circular status lamp, compact system typography, no decorative metaphor.

**STORY:** See recording state, act once, notice only actionable warnings, then browse recent clips. Maintenance opens only on request.

**FIRST VIEWPORT:** Quiet header; a large left-aligned “Recording is on/off” state; one adjacent tactile on/off button; compact camera, storage, and retention facts below; recent recordings begin before the fold.

**FORM:** Architectural wall-control faceplate, candidate 6, seed `b1102044`.

**FINISH:** unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
